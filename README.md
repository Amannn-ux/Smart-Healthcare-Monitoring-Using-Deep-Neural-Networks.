# Smart-Healthcare-Monitoring-Using-Deep-Neural-Networks.

This project is a smart healthcare system that uses a Deep Neural Network (DNN) model to predict patient diseases based on wearable sensor data such as:
Temperature
Heart Rate
Respiration Rate
Blood Oxygen Level

The trained model can classify diseases like:
Food Poisoning
Healthy
Jaundice
Viral Fever

A Flask API serves the model predictions and simulates a UAV (Unmanned Aerial Vehicle) making decisions based on patient data.
This hybrid system aims to demonstrate how AI and UAVs can assist in remote medical diagnosis and emergency healthcare support.
